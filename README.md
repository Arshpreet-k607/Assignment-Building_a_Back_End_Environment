Introduction:
This project implements a basic back-end environment using Node.js, Express, and TypeScript.
The purpose of the assignment is to demonstrate the ability to set up a server, create API endpoints, 
organize files using a clean folder structure, and verify functionality through automated testing and API client screenshots.
The project includes two main API endpoints:
- A health check endpoint
- A portfolio performance calculation endpoint

How to Run the Project

Install all required packages:

npm install
Start the development server:

npm run dev
Build the TypeScript files:

npm run build
Run the tests:

npm test

Portfolio Logic
The portfolio calculation is done in a separate file.
It takes the initial investment and current value, calculates the profit, and shows whether the portfolio gained or lost value.
